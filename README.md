🛒 ApiCommerce

API RESTful desarrollada con Node.js y Express que permite gestionar productos y usuarios para un sistema e-commerce.
Incluye autenticación con JWT, manejo de carrito de compras y persistencia de datos en MongoDB.

🚀 Características

Registro de usuarios

Login con generación de token JWT

Autorización mediante middleware

CRUD básico de productos

Carrito de compras:

Agregar productos

Eliminar productos

Ver carrito del usuario autenticado

Base de datos MongoDB

Arquitectura estructurada por controladores y rutas

🧱 Tecnologías utilizadas

Node.js

Express.js

MongoDB

Mongoose

JSON Web Token (JWT)

Bcrypt

📌 Objetivo del proyecto

Este proyecto fue desarrollado como práctica de backend para demostrar:

Manejo de autenticación con JWT

Integración con MongoDB

Diseño básico de una API REST

Separación de responsabilidades (routes, controllers, models)
